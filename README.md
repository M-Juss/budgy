# budgy

A personal finance tracking application designed to help users manage, organize, and understand their money with clarity and ease.

## Overview

**budgy** is a full-stack application that allows users to track their income and expenses in their daily lives. It provides a clear overview of financial activity while offering insightful analytics across different time ranges—daily, weekly, monthly, and yearly.

The goal of this project is to make personal finance management simple, intuitive, and data-driven, helping users build better financial habits through visibility and understanding.

## Features

* 📥 Track incoming money (Income)
* 📤 Record outgoing money (Expenses)
* 📊 Visual analytics and reports
* 📅 Breakdown of finances by:

  * Daily
  * Weekly
  * Monthly
  * Yearly
* 🔐 Secure authentication using JWT
* 🧾 Organized transaction history

## Tech Stack

### Frontend

* React.js
* Tailwind CSS

The frontend is designed to be clean, responsive, and user-friendly, focusing on simplicity and usability.

### Backend

* Node.js / Express (assumed backend framework)
* MongoDB (NoSQL database)

The backend handles data storage, user authentication, and API logic, ensuring efficient and scalable data management.

### Authentication

* JWT (JSON Web Tokens)

Provides secure and stateless user authentication.

### Analytics

* Chart.js

Used to visualize financial data and generate meaningful insights through charts and graphs.

## How It Works

Users can log their daily income and expenses, which are stored in the database and categorized accordingly. The system then processes this data to generate visual analytics, helping users understand spending patterns and financial trends over time.

## Purpose

This project was built to:

* Help users gain control over their personal finances
* Provide clear insights into spending habits
* Practice building a full-stack application with real-world use cases
* Explore data visualization and analytics integration
